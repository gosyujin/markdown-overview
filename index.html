Markdown Overview

🔒 通信・保存なし
または、ファイルをこのページにドロップ

左の入力欄に Markdown を貼り付けると、ここに表示されます。

  • コードブロックと表は、ホバー／フォーカスで「コピー」ボタンが出ます。
  • Mask に切り替えると、マスク設定の定義に従って語句を置換して表示します。
  • 貼り付けた内容は、このタブのメモリ上にしか存在しません。

マスク設定

1行に1つ、元の語句, 置換後の語句 の形式で書きます（=> / -> / タブ区切りも可。# 始まりはコメント）。 長い語句が優先され、大文字小文字は区別します。

この定義はどこに保存される？

どこにも保存されません。このタブのメモリ上だけに保持され、リロードや閉じると消えます（localStorage・Cookie・通信は使いません）。 毎回入力するのが面倒な場合は、下でパスフレーズ付きの暗号化ファイルとして手元に保存し、次回そのファイルを読み込んでください。 暗号化はお使いのブラウザ内（AES-256-GCM / PBKDF2）で完結します。
